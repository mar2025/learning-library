Hands On Lab - Prerequisites

This document outlines some example Docker Engine environment installs

The Docker Engine environment needs to be completed prior to starting the Hands on Lab.

These examples are only a few of the many that you might utilize to create a Docker Environment.

Use a Worker node on your Oracle Container Cloud Service instance:

  1. Request An Oracle Cloud Trial
  2. Create a Container Cloud Service Instance: See Oracle Tutorial | Youtube Video

Use Oracle VirtualBox:

  • Get and Install VirtualBox for your Laptop
  • Create a Linux VM with VirtualBox
  • Install Docker Engine

As an option for a VirtualBox VM: Download a prebuilt OL7 VM (DOC-1002902.ova) | Docs and Docker install

Use Docker Engine on Windows:

  • See Install Docker for Windows

Use Docker Engine on Mac:

  • See Install Docker for Mac

Use Docker Engine on Oracle Linux:

  1. Request An Oracle Cloud Trial
  2. See the first 3 sections of this blog for a quick install on an Oracle Linux 6 Cloud VM

Note - after you have your Docker environment built, you will be ready to start the Participant Guide
