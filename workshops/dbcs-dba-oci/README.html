Oracle Database Cloud Service for DBAs Workshop

How to use this workshop

  • The Lab documentation is best viewed by using the Workshop's GitHub Pages Website URL. Once you are viewing the Workshop's GitHub Pages website, you can see a list of Lab Guides at any time by clicking on the Menu Icon after selecting the version of the workshop you want to use:

  • This workshop has multiple versions. If you use the GitHub Pages link above, you will be presented with a version selection page. If you prefer to browse the workshop using the GitHub repository view, you should choose one of the following files to get started:

  • IL-Readme.md: This version of the workshop assumes you are participating in an Oracle sponsored (and led) workshop that has environments setup and configured in advance.

  • SG-README.md: This version of the workshop assumes you wish to work through the workshop with your own account (trial account or customer account), and that you (or someone in your organization) will run the setup steps to prepare the environment. Note that this will take additional time, and will involve periods of wait while services are provisioned. Further, lab 100 is slightly different due to setup step differences.
